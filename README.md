# intelligent-task-assignment-system

A ServiceNow project that dynamically assigns Incidents, Requests, or Change Tasks based on:

- Skills & Competencies
- Workload balancing (open tickets vs SLAs)
- Past performance / resolution times

## ⚙️ Features
- Calculated task assignment
- Integration with Microsoft Teams/Slack for auto-assignment notifications
- Competency Dashboard with interactive charts
- Flow Designer & Business Rules automation

## 🧠 Skills Highlighted
- ServiceNow ITSM
- Flow Designer
- Business Rules
- Integrations
- Data-driven decision making
